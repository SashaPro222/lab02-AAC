«Ответы на контрольные вопросы»

1) IL — это промежуточный код, который появляется после компиляции C#-программы. Он нужен, чтобы отделить исходный код от конкретной архитектуры процессора
2) Потому что сборка .NET содержит IL-код и метаданные. Благодаря этому инструменты вроде ILSpy могут восстановить код, близкий к исходному.
3)В Debug присутствуют лишние инструкции nop, которых нет в Release.
В Release уменьшилось количество промежуточных операций с локальными переменными
4)Потому что при сборке Release компилятор  убирает лишние операции.Debug же создается для удобства отладки, и производительность в нем не является главной целью.
5)Потому что обычные строки хранятся внутри .dll как текст, без шифрования. Их легко можно обнаружить внутри файла с помощью HEX-редактора.
